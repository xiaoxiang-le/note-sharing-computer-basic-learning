### 浮点数计算
浮点数加减法分为 **对阶 → 尾数运算 → 规格化 → 舍入 → 溢出判断** 五个主要步骤。
### 步骤 1：对阶

- **目的**：使两个数的阶码相等，以便尾数可以直接相加减。
    
- **做法**：
    
    1. 计算阶差 ΔE = E_x - E_y（E 为阶码）。
        
    2. 若 ΔE = 0，已完成对阶。
        
    3. 若 ΔE > 0，则阶码小的数（y）的尾数右移 ΔE 位，且其阶码增加 ΔE 变为 E_x。
        
    4. 若 ΔE < 0，则阶码小的数（x）的尾数右移 |ΔE| 位，其阶码增加 |ΔE| 变为 E_y。
        
- **注意**：右移时低位会丢失，通常用额外位（保护位、舍入位、粘位）暂存，以保证舍入精度。
    

### 步骤 2：尾数运算

- **目的**：根据符号位和尾数进行加法或减法。
    
- **做法**：
    
    - 如果两个数符号相同 → 尾数相加。
        
    - 如果两个数符号不同 → 将减法转换为加法：取绝对值大的数减去绝对值小的数，结果的符号与绝对值大的数相同。
        
- **实际计算**：尾数通常用原码表示，运算时需要考虑符号。为简化，可转为补码运算或直接处理。
    

### 步骤 3：规格化

- **目的**：使尾数形式为 `1.xxxx`（二进制），即最高有效位为 1。
    
- **处理规则**：
    
    - **左规**：若尾数最高位为 0（例如 `0.1xxxx`），则尾数左移一位，阶码减 1，重复直到尾数最高位为 1。
        
    - **右规**：若尾数运算产生了进位（例如 `10.xxxx`），则尾数右移一位，阶码加 1。注意右移可能导致最低位丢失，需结合舍入处理。
        
- **特殊情况**：若尾数为 0，则阶码置为最小（如单精度 -126），结果为 0。
    

### 步骤 4：舍入

- **目的**：在有限位数下决定是否对尾数末位加 1，以接近真实值。
    
- **常用舍入模式**（IEEE 754）：
    
    - **就近舍入（默认）**：结果最近的可表示值；若距离相等，取最低位为 0。
        
    - **朝 0 舍入**：向原点方向截断。
        
    - **朝 +∞ 舍入**：向上取整。
        
    - **朝 -∞ 舍入**：向下取整。
        
- **做法**：根据右移时丢掉的保护位、舍入位、粘位，判断是否需要进位。若进位导致尾数再次溢出，需再右规一次。
    

### 步骤 5：溢出判断

- **阶码上溢**：规格化或舍入后，阶码超过最大值（单精度 127）。结果置为 ±∞。
    
- **阶码下溢**：阶码小于最小值（单精度 -126）。结果置为 0 或非规格化数（若支持）。
    
- **尾数溢出**：已在右规时处理。
