### 如何判断一个排序算法是否稳定？

核心在于看它**在排序过程中是否会改变相等元素的原始相对顺序**。

### 1. 冒泡排序（Bubble Sort）

- **原理**：重复遍历待排序序列，每次比较相邻元素并交换逆序对，每趟将最大（或最小）元素“浮”到末端。
    
- **步骤**：
    
    1. 从第一个元素开始，比较相邻元素，如果前者大于后者则交换。
        
    2. 对每一对相邻元素重复，末尾元素成为最大元素。
        
    3. 忽略末尾已排好元素，重复上述过程直到无交换。
        
- **时间复杂度**：
    
    - 最好：O(n)（已有序，改进版提前终止）
        
    - 最坏：O(n²)（完全逆序）
        
    - 平均：O(n²)
        
- **空间复杂度**：O(1)
    
- **稳定性**：稳定（相等元素不交换）
### 2. 选择排序（Selection Sort）

- **原理**：每次从未排序部分选择最小（或最大）元素，放到已排序部分的末尾。
    
- **步骤**：
    
    1. 在未排序序列中找到最小值，记录其索引。
        
    2. 将最小值与未排序部分的第一个元素交换。
        
    3. 重复直至全部有序。
        
- **时间复杂度**：始终 O(n²)（比较次数固定 n(n-1)/2）
    
- **空间复杂度**：O(1)
    
- **稳定性**：不稳定（如 [5, 3, 5, 2] 交换会将两个5的相对顺序改变）
### 3. 插入排序（Insertion Sort）

- **原理**：构建有序序列，对于未排序元素，在已排序序列中从后向前扫描，找到合适位置插入。
    
- **步骤**：
    
    1. 从第二个元素开始，视为待插入元素。
        
    2. 与已排序部分从右向左比较，若已排序元素大于待插入元素则将其右移。
        
    3. 找到合适位置插入。
        
- **时间复杂度**：
    
    - 最好：O(n)（已有序）
        
    - 最坏：O(n²)（逆序）
        
    - 平均：O(n²)
        
- **空间复杂度**：O(1)
    
- **稳定性**：稳定（相等时会插在相同元素后面）
### 4. 希尔排序（Shell Sort）

- **原理**：插入排序的改进，按一定间隔（增量）分组，对每组进行插入排序，逐步缩小增量直到1。
    
- **步骤**：
    
    1. 选择增量序列（如 n/2, n/4, ..., 1）。
        
    2. 对于每个增量 gap，将相距 gap 的元素视为一组，组内插入排序。
        
    3. 逐步缩小增量，最后 gap=1 时整体插入排序。
        
- **时间复杂度**：依赖增量序列，最好 O(n log² n)，平均 O(n^1.3) ~ O(n^1.5) 不等，最坏 O(n²)
    
- **空间复杂度**：O(1)
    
- **稳定性**：不稳定（分组排序可能打乱等值元素顺序）
### 5. 归并排序（Merge Sort）

- **原理**：分治法。将序列分成两半分别排序，然后合并两个有序子序列。
    
- **步骤**：
    
    1. 递归地将序列分成两半直到长度为1。
        
    2. 合并两个有序子序列：依次比较头部元素，放入临时数组。
        
    3. 将临时数组复制回原数组。
        
- **时间复杂度**：始终 O(n log n)
    
- **空间复杂度**：O(n)（需辅助数组）
    
- **稳定性**：稳定（合并时左边优先）
### 6. 快速排序（Quick Sort）

- **原理**：分治法。选取基准（pivot），将小于基准的元素放左边，大于的放右边，递归对两边排序。
    
- **步骤**：
    
    1. 选择基准（通常首、尾或随机）。
        
    2. 分区：双指针或单指针，将小于基准的交换到左侧。
        
    3. 基准放到正确位置，返回分界点。
        
    4. 递归处理左右子区间。
        
- **时间复杂度**：
    
    - 最好：O(n log n)（每次均匀分割）
        
    - 最坏：O(n²)（已有序且选首尾为基准）
        
    - 平均：O(n log n)
        
- **空间复杂度**：递归栈平均 O(log n)，最坏 O(n)
    
- **稳定性**：不稳定（交换操作可能改变相对顺序）
### 7. 堆排序（Heap Sort）

- **原理**：利用堆数据结构（大顶堆/小顶堆）进行选择排序。
    
- **步骤**：
    
    1. 将数组构建成大顶堆（升序用大顶堆）。
        
    2. 交换堆顶（最大值）与堆尾，堆大小减1。
        
    3. 对堆顶执行向下调整，恢复堆性质。
        
    4. 重复2-3直至全部有序。
        
- **时间复杂度**：始终 O(n log n)（建堆 O(n) + n 次调整 O(log n)）
    
- **空间复杂度**：O(1)（原地排序）
    
- **稳定性**：不稳定（堆调整可能打乱等值元素顺序）
