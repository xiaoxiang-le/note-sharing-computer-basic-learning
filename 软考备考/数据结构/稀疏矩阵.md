稀疏矩阵是指矩阵中非零元素个数远少于零元素个数。为了节省存储空间和计算时间，通常不存储所有零元素，而是只存储非零元素及其位置信息。
```
  列0  1  2  3  4  5
0 [0, 0, 3, 0, 0, 0]
1 [0, 0, 0, 0, 7, 0]
2 [1, 0, 0, 0, 0, 0]
3 [0, 0, 0, 5, 0, 0]
4 [0, 9, 0, 0, 0, 0]
```
常见的压缩存储方式包括：
1. **三元组顺序表**
    
    - 用一个结构数组（或链表）来存储非零元素，每个元素记录三个值：**行下标、列下标、元素值**。
        
    - 按行或按列顺序排列，适合存储静态稀疏矩阵，常用于转置、乘法等运算。
```c
   typedef struct {
    int row, col;
    int value;
} Triple;

Triple matrix[] = {
    {0, 2, 3},
    {1, 4, 7},
    {2, 0, 1},
    {3, 3, 5},
    {4, 1, 9}
};
int rows = 5, cols = 6, nums = 5; 
```
1. **十字链表**
    
    - 是链式存储结构，每个非零元素对应一个结点，包含行、列、值以及指向同行下一个非零元素的指针和同列下一个非零元素的指针。
        
    - 方便插入、删除和动态修改，适合频繁变化的稀疏矩阵。
    
    - 每个节点包含：`row`, `col`, `value`, `right`（指向同行下一个非零）, `down`（指向同列下一个非零）。同时维护行头数组和列头数组。
```c
    typedef struct OLNode {
    int row, col;
    int value;
    struct OLNode *right, *down;
} OLNode, *CrossList;
```
**对于上述矩阵的十字链表示意**：

- 行头数组 `row_head[0..4]`，列头数组 `col_head[0..5]`。
    
- 按行链接：
    
    - 第0行：(0,2,3) → NULL
        
    - 第1行：(1,4,7) → NULL
        
    - 第2行：(2,0,1) → NULL
        
    - 第3行：(3,3,5) → NULL
        
    - 第4行：(4,1,9) → NULL
        
- 按列链接：
    
    - 第0列：(2,0,1) → NULL
        
    - 第1列：(4,1,9) → NULL
        
    - 第2列：(0,2,3) → NULL
        
    - 第3列：(3,3,5) → NULL
        
    - 第4列：(1,4,7) → NULL
        
    - 第5列：NULL
    实际上十字链表中每个节点同时属于行链表和列链表，通过 `right` 和 `down` 指针连接。例如节点 (2,0,1) 的 `right` 为 NULL（该行只有它），`down` 指向同列的下一个节点（若无则为 NULL）。插入或删除一个节点只需修改前后指针，非常灵活。
